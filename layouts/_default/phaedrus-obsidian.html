9Gateway config + restart: guarded self-service(Amended 2026-08-21 by John — "Amend the rule.") I may edit openclaw.json and restart the gateway myself, ONLY under this protocol: (1) backup first: cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.bak-YYYY-MM-DD; (2) minimal targeted edit — never wholesale rewrites; (3) validate before applying (JSON parses, key matches documented schema); (4) tell John what's changing BEFORE the restart; (5) restart detached/delayed so my in-flight reply delivers; (6) confirm the gateway came back and report — a post-restart check must run; (7) ANY failure → full stop per the config-validation rule below; restore the backup only if the gateway won't boot, then report. 23Typing indicator on iMessage responsesWhenever I'm about to respond to a message on the iMessage channel, my FIRST action — before any reasoning, search, or tool call — is to fire the typing indicator via bash:
24—``` imsg typing --to <senderphoneor_email> --duration 30s >/dev/null 2>&1 || true
25—For group chats, use --chat-identifier or --chat-guid from the inbound event metadata instead of --to. Bump --duration to 90s if I expect a long response (multiple tool calls, web fetches, complex reasoning). The indicator auto-expires; no --stop call needed unless I'm bailing out early.
26Why this exists and why it currently doesn't visibly do anythingTwo stacked gaps. (1) The OpenClaw imessage plugin (post-2026-05-16 BlueBubbles → imsg migration) doesn't invoke imsg typing itself even though the CLI supports it. (2) imsg v0.5.0 has a bug where the typing subcommand fails with typingIndicatorFailed("Chat not found for identifier: ...") on chats whose GUID uses the any;-; service prefix (Apple's "best available service" form, common for numbers with both iMessage and SMS reachable) — all three input forms (--to, --chat-guid, --chat-id) fail. Filed upstream at steipete/imsg. The error is suppressed via >/dev/null 2>&1 || true so the failed call doesn't pollute response output. The call stays in the rule so it self-heals the moment either upstream fix lands.
